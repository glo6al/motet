# Motet brand assets

The Motet wordmark is outlined lettering. The whole note stands alone as the app icon, favicon and touch icon. The wordmark appears in the sidebar, on the unlock screen and at the top of the README.

| Where | Assets |
| --- | --- |
| `brand/lookout/` | 76 artwork exports covering SVG and PNG wordmarks, standalone marks, favicons and app icons, including ICO and ICNS packages. |
| `src/web/static/` | 11 copies for the app sidebar, unlock screen, browser tabs and Apple touch icons. |
| `docs/media/` | 3 README wordmark SVGs and 9 demo screenshots that show the wordmark. |

[Artwork, sizes and build instructions](lookout/README.md)
