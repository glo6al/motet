# Workspace interface

Open `http://127.0.0.1:8793/` while Motet is running to use Workspace on desktop or phone. Use `?demo` to look around with fictional sessions. Use `?ui=classic` for the previous interface or `?demo&ui=classic` for its demo. The interface choice applies to the current URL and carries through Unlock.

- Use the sidebar to step up to a session, find a project or open **Motet**.
- At a desk, the conversation shows recorded messages and folds runs of steps into expandable groups. Open Work to inspect the available activity, changes or preview.
- The bell shows alerts and requests. Configure notifications and local recording under Settings.
- **New chat** and attachment controls appear where the local app, session and host configuration support them. Use [Motet file reading](MOTET_FILE_READING.md) to set up PDF and PNG questions.

For current provider capabilities, see the [README](../README.md#current-provider-capabilities).
